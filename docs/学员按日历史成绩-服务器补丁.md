# 学员按日历史成绩：服务器补丁

交付批次：`ynu-personal-history-20260927`。适用于现有 `/opt/ynu-shooting` 部署、`ynu-shooting` systemd 服务及本机 PostgreSQL `ynu_shooting` 数据库；需已安装混合赛制版本，运行环境为 JDK 21。

本包包含最新后端 JAR，给个人历史接口补充真实训练起止时间，支持日期卡片、当日多次训练和逐轮折线图。也包含此前的教员历史补录后端。本人预约粉色与教员值班日历属于前端更新，需另行上传小程序。

## 上传与执行

将压缩包及同名 `.sha256` 文件上传到 `/home/ubuntu/ynu-deploy`，执行：

```bash
cd /home/ubuntu/ynu-deploy
sha256sum -c ynu-personal-history-20260927.tar.gz.sha256
tar -xzf ynu-personal-history-20260927.tar.gz
cd ynu-personal-history-20260927
sudo bash upgrade-coach-daily.sh
```

脚本先校验文件和前置结构，备份现有 JAR，停止服务后备份数据库，再执行可重复运行的提醒表、历史补录兼容迁移，安装 JAR 并检查 API。备份保存在 `/var/backups/ynu-shooting/coach-daily.*`，实际路径会输出。保留现有微信、邀请码、数据库和提醒配置，服务会短暂停止。

本次“按日历史视图”本身没有新增数据库结构；保留两份既有兼容迁移，是为了覆盖尚未安装上一包的服务器。已安装历史补录版本也可直接使用本包。

失败时脚本只在确认没有独立历史补录记录时自动恢复旧 JAR。有历史记录或无法确认数据库状态时会保持服务停止，避免旧程序读取不兼容数据；请保留终端输出和备份，查看服务日志后处理。不会自动用旧备份覆盖数据库。

## 升级后检查

```bash
sudo systemctl status ynu-shooting --no-pager
sudo journalctl -u ynu-shooting --since '10 minutes ago' --no-pager
sha256sum /opt/ynu-shooting/backend.jar
```

安装后的 JAR 哈希应与包内 `SHA256SUMS` 的 `backend.jar` 行一致；源码提交及打包状态见 `BUILD-INFO.json`。

随后上传新的微信小程序构建（`frontend/dist/teamtest/mp-weixin`）。用已有训练记录的学员账号检查“我的成绩 → 日期 → 当天训练 → 成绩折线图”，同时检查教员值班入口与粉色本人预约。后端健康检查不代表微信真机验收完成。

本包不含生产配置、账号密钥、数据库数据和小程序上传操作。详细功能与本地验证记录见 `FEATURES.md`。
