# 学员按日历史成绩

开发日期：2026-09-27。入口为「我的 → 我的成绩与历史最佳」。

- 首页按训练开始日展示大日期卡片，日期倒序排列；每张卡片显示训练次数及各枪种、赛制的当日最高成绩。个人历史最佳保留在日期列表下方。
- 点击日期，查看当天各次训练的实际起止时间、器械和分赛制最终成绩，按开始时间升序排列。同次混合赛制训练只计算一次；未登记成绩、训练中及教员补录记录均保留入口。
- 点击单次训练，查看实际轮数、训练时长、最终成绩及逐轮折线图。决赛和资格赛分别显示，保留原始轮次编号；只有一轮时显示单点，旧版仅有总成绩时提示无逐轮记录，不虚构曲线。
- 补登或更正仍归原训练开始日，跨午夜训练归开始当天，结束时间显示跨日日期。原登记、补登、恢复和结束训练操作继续保留。
- 本人训练预约和值班预约卡片及图例使用 `#f2baae`，搭配深色文字。

## 接口和部署

`GET /api/training/records/me` 增加 `trainingSessions` 字段，返回本人有权查看的训练元信息，包括实际开始、结束时间。既有 `personalBests`、`sessions`、`unscoredSessions` 字段保持兼容；单次详情继续使用本人权限接口，不复用教练管理权限。

本次无数据库结构变更，但上线须先更新后端 JAR，再上传新小程序前端。后端未更新时，新前端会明确提示，避免把缺失的数据误显示为“没有训练”。此前交付的历史补录补丁包不包含本次变更，不能用旧包更新本功能。
