# 教员值班预约视图

开发日期：2026-09-27。本次为前端调整，复用已有值班接口、权限和数据；不需要新增数据库迁移或更新后端 JAR。尚未进行本次微信真机验收或上传发布。

## 使用入口

- 底部「预约」页面，在「预约日程」右侧新增「教员值班」。仅经过接口确认的教练员（admin / superadmin）可见，学员和访客不显示。
- 「我的 → 我的值班安排」保留快捷跳转，原大块值班面板迁入预约页。
- 旧微信值班提醒的 `pages/my/my?dutyDate=YYYY-MM-DD` 链接继续兼容，确认教练身份后自动转到新视图并定位日期。

## 日程与操作

- 使用与射击预约相同的日期条、三天并排日历、六个训练时段，默认浏览今天至未来第七天。
- 粉色（`#f2baae`）卡片表示本人的值班，显示已预约、已到岗、待确认离场、已离场或未到岗状态；其他卡片显示排班人数。
- 点击卡片在日历下方查看时段及教员名单，预约本人值班、取消未到岗排班、确认到岗或查看微信提醒状态。同一时段允许多位教员共同值班。
- 当前场地卡片显示到岗人数、训练人数及本人离场操作；到岗时间窗口、取消保护和交接保护仍由原接口校验。
- 页面每 30 秒更新；切换页面停止轮询。提交后刷新日历，失败时展示接口原因，读取失败时清除可操作的旧数据。
