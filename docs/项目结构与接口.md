## 2. 页面与组件

| 页面 | 职责 |
| --- | --- |
| `pages/index/index.vue` | 场地首页、手枪／步枪入口、当前设备状态 |
| `pages/booking/booking.vue` | 时段日程、我的预约、过往训练、预约／立即训练确认与提醒 |
| `pages/leaderboard/leaderboard.vue` | 综合榜项目／指标／性别筛选 |
| `pages/my/my.vue` | 资料、身份、教练值班、个人成绩与教练管理入口 |
| `pages/login/login.vue` | 微信／本地开发登录、资料登记、邀请码开通 |
| `pages/training/results.vue` | 本人多轮成绩、结束／补登／恢复、个人历史 |
| `pages/training/history-entry.vue` | 教员搜索学员、补录历史起止时间与实际轮次成绩 |
| `pages/training/coach.vue` | 日期卡片 → 当日分组排名 → 单次训练与更正 |

`RoundTrend.vue` 用原生 view 和 CSS 线段展示轮次图，无额外图表依赖；`ReminderButton.vue` 在用户点击后调用微信订阅授权，再持久化当前目标提醒。`VenueDutyPanel.vue` 提供教练本人排班与到离场操作。

`domain/` 保留可直接测试的日期、配额、状态、分组校验、成绩展示及曲线坐标逻辑；`services/request.js` 统一注入 Bearer token、处理超时与登录失效。前端允许的按钮不是权限边界，后端仍检查用户、状态与所有权。

## 3. 后端核心职责

| 模块 | 关键实现 |
| --- | --- |
| 身份与开通 | `AuthServiceImpl`、`WechatIdentityService`、`CoachInvitationService`、`AuthContext` |
| 预约与可用性 | `BookingServiceImpl`；未来预约和当前立即训练分别判断 |
| 场地和值班 | `VenueAccess` 统一锁顺序，`VenueDutyService` 排班／到岗／离场／交接 |
| 训练生命周期 | `TrainingServiceImpl`、`TrainingResumePolicy` |
| 多轮成绩与发布 | `TrainingResultsService`，分模式结算和本人历史 |
| 教练成绩 | `CoachResultsService`，按日聚合、名单、单次详情和更正 |
| 综合榜 | `LeaderboardService`，基于已发布成绩计算，与当日榜分开 |
| 提醒 | `WechatReminderService` 队列／状态；`WechatReminderMessage` 模板；`WechatSubscriptionClient` 微信接口 |
| 后台任务 | `BookingNoShowScheduler` 约 60 秒；`WechatReminderScheduler` 约 15 秒 |
| 余量通知 | `SlotPushService` 事务提交后广播；前端目前主要轮询及操作后刷新 |

不是独立微服务集群；后端为一个 Spring Boot 应用。服务器支持 WebSocket，但当前前端没有完成 WebSocket 订阅／重连接入。

## 4. REST 接口索引

以下是实际控制器路由。API 基址在 Nginx 后通常带 `/ynu-shooting`，应用内部路径如下。统一响应 `{code,message,data,timestamp}`，成功 `code=0`。

| 方法与路径 | 用途／权限 |
| --- | --- |
| POST `/api/auth/login` | 微信 code 换登录；mock 仅本地／integration 明确启用 |
| POST `/api/auth/profile` | 本人资料登记／更新 |
| GET `/api/auth/me` | 当前用户资料与角色 |
| POST `/api/auth/coach-activation` | 当前用户通过邀请码开通教练 |
| GET `/api/bookings/slots?date=...` | 时段余量，访客可读；可选 deviceType |
| GET `/api/bookings/slots/details?date=...&slotId=...` | 分权限投影的时段安排 |
| POST `/api/bookings` | 本人创建未来预约 |
| POST `/api/bookings/walk-in` | 当前时段直接进入训练 |
| GET `/api/bookings/me` | 本人预约历史 |
| GET `/api/bookings/{id}` | 本人或教练查看预约 |
| POST `/api/bookings/{id}/cancel` | 本人取消或教练处理可取消记录 |
| POST `/api/bookings/{id}/checkin` | 本人签到 |
| GET／PUT `/api/users/me/availability` | 本人可训练时间；PUT body 含 date、slotIds |
| POST `/api/training/start/{bookingId}?mode=...` | 本人已签到预约开始训练 |
| POST `/api/training/finish/{sessionId}` | 本人结束并按模式结算 |
| POST `/api/training/resume/{sessionId}` | 本人恢复符合条件的原训练 |
| POST `/api/training/{id}/attempts` | 本人登记／补登轮次；requestKey、mode、groupTotals |
| GET `/api/training/{id}/results` | 本人单次训练成绩 |
| GET `/api/training/records/me` | 本人历史、个人最佳、未登分训练 |
| GET `/api/training/me` | 本人训练记录兼容接口 |
| POST `/api/training/score` | 教练旧版逐发录分兼容接口 |
| GET `/api/coach/training/members?search=...&page=0` | 教员按姓名或学号搜索已完善资料的成员 |
| POST `/api/coach/training/history` | 教员补录整场历史训练，幂等提交 |
| GET `/api/coach/training/days?page=0` | 教练日期卡片，每页 30 个日期 |
| GET `/api/coach/training/days/{date}` | 教练读取完整当日分项目排名 |
| GET `/api/coach/training?search=...&page=0` | 旧版教练列表兼容接口，每页 30 条训练 |
| GET `/api/coach/training/{id}` | 教练单次训练详情／可更正记录 |
| PUT `/api/coach/training/{id}/attempts/{recordId}` | 更正轮次，须 expectedState 和 reason |
| PUT `/api/coach/training/{id}/legacy-scores/{recordId}` | 更正无对应轮次的旧版总分 |
| GET `/api/leaderboard` | 公开综合榜：weapon、event、metric、gender、limit |
| GET／POST／DELETE `/api/reminders/{kind}/{id}` | 本人查询／订阅／取消提醒，kind 为 TRAINING 或 DUTY |
| GET／POST `/api/admin/devices` | 教练查询／新增设备 |
| PATCH `/api/admin/devices/{id}/status` | 教练维护设备；不能手工抢改使用中状态 |
| GET `/api/admin/schedules?date=...` | 教练读取排班 |
| POST `/api/admin/schedules` | 教练添加排班；adminId、slotDate、slotId 参数 |
| DELETE `/api/admin/schedules/{id}` | 教练删除符合条件的排班 |
| GET `/api/admin/duty?date=...` | 教练读取当前到岗人数、活跃训练及当天排班 |
| POST `/api/admin/schedules/{id}/arrive` | 排班教练本人到岗 |
| POST `/api/admin/duty/depart` | 当前教练离场，关闭本人开放到岗记录 |
| GET `/api/admin/bookings` | 教练查询预约，可选 date |
| POST `/api/admin/bookings/{id}/cancel` | 教练取消可处理预约 |
| POST `/api/admin/bookings/{id}/no-show` | 教练标记已超时未签到的预约 |
| GET `/api/admin/no-shows`、`/cancellations`、`/audit` | 教练读取管理记录；部分接口支持 userId |

前端综合榜常用参数：weapon 为 PISTOL／RIFLE；event 为 FINAL／QUALIFICATION；metric 为 BEST／AVG5／PB30D／IMPROVE；gender 为 ALL／M／F；limit 为 1–100。其他训练接口模式值使用 `final_`／`qualifying`，不要混用两套枚举。

WebSocket 入口：`/ws/slots?date=YYYY-MM-DD`，为普通 WebSocket 消息，不是 STOMP/SockJS。

## 5. 仓库中没有的组件

没有旧规划中的 `server/` Node 后端、原生 `miniprogram/` 第二套前端、Redis/Redisson、Flyway 迁移目录、Spring Security filter、独立备份控制台、候补队列表、CI 工作流或已配置覆盖率门槛。后续需求应从[版本总览](当前版本总览-v1.0.0.md)的待办选择，不直接执行早期 `.specify/tasks.md`。
